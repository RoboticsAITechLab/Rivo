sequenceDiagram autonumber actor User as User Browser / Client participant Edge as Edge Middleware (apps/web/src/middleware.ts) participant Route as Auth Route (/api/auth/login) participant Scrypt as Crypto Engine (lib/auth/crypto.ts) participant DB as Neon PostgreSQL (Prisma) participant Redis as Upstash Redis (rivo:session:*) User->>Route: POST /api/auth/login { email, password, rememberMe } Route->>DB: Query User by email with memberships & MFA DB-->>Route: User Record (passwordHash, status, mfa) Route->>Scrypt: verifyPassword(password, user.passwordHash) Scrypt-->>Route: Valid Boolean alt Invalid Password Route-->>User: HTTP 401 { message: 'Invalid email or password.' } else Valid Password alt MFA Enabled Route->>DB: Generate MfaChallenge token Route-->>User: HTTP 200 { requireMfa: true, challengeToken } else MFA Disabled / Verified Route->>Route: generateSecureToken(32) -> rawToken Route->>Route: hashToken(rawToken) -> tokenHash Route->>DB: Create Session row (tokenHash, userId, schoolId, expiresAt) Route->>Redis: Cache Session (rivo:session:tokenHash) Route-->>User: HTTP 200 (Set-Cookie: rivo_session=rawToken) end end
