# Homework Assignment Workflow

This workflow covers the creation, publication, and tracking of homework tasks.

---

## 1. Homework Assignment Cycle

```
[Teacher Creates Homework]
            │
            ▼
[Attaches Subject, Due Date, Description, Materials]
            │
            ▼
[Saves as Draft OR Publishes Directly]
            │
            ▼
[Published: Appears on Student & Parent Dashboards]
            │
            ▼
[Due Date Passes: Archived to Completed History]
```

---

## 2. Step-by-Step Procedure

### Step 1: Initialize Assignment
1. Navigate to `/school/homework` and click **New Homework**.
2. Select target Class and Section.
3. Select Subject from the Subject Catalog.

### Step 2: Content & Deadlines
1. Enter assignment Title (e.g., "Algebra Chapter 4 Practice Problems").
2. Enter detailed instructions or problem numbers in the Description editor.
3. Select Due Date and submission deadline time.
4. (Optional) Upload supplementary worksheets or PDF reference sheets (up to configured size limit, default: 10MB).

### Step 3: Publication
1. Save as `DRAFT` if further review is needed.
2. Click **Publish Assignment**.
3. The assignment transitions to `PUBLISHED` status.
4. Instant alerts are triggered to enrolled students and parents via In-App alerts and push notifications.

---

## 3. Implementation Boundary

> [!NOTE]
> **MVP Scope**: Teachers assign and publish homework; students and parents view assignments and deadlines. Digital submission of student homework files through the portal is not part of the current MVP release.
