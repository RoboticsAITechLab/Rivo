## 1. Feature Status Classification Definitions

- **IMPLEMENTED:** Complete end-to-end stack exists and connects: UI $\rightarrow$ API Route $\rightarrow$ Business Service $\rightarrow$ Prisma Database Model.
- **PARTIALLY_IMPLEMENTED:** Core flows connect and function, but specific tabs, trigger buttons, server-side PDF exports, or mobile views are incomplete.
- **UI_ONLY:** Frontend view exists but communicates with mock state or returns simulated data without PostgreSQL persistence.
- **BACKEND_ONLY:** API routes and domain services exist but have no corresponding frontend UI trigger.
- **NOT_IMPLEMENTED:** Planned or referenced in documentation, but no source code or database models exist.
- **BROKEN / BLOCKED:** Fails due to schema mismatch, runtime exception, or broken integration.
