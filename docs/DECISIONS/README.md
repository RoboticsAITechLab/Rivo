# Architectural Decision Records (ADRs)

> **Last Verified:** November 11, 2026  
> **Status:** Code-Verified Decisions Repository

---

## 1. Overview

This directory contains formal Architectural Decision Records (ADRs) capturing critical technical, operational, and architectural decisions made throughout RIVO's engineering lifecycle.

Each ADR records:
- **Decision ID:** Sequential identifier (e.g., `ADR-001`).
- **Title:** The architectural decision being made.
- **Status:** `VERIFIED` (supported by current source code) or `INFERRED` (deduced from code patterns).
- **Context:** The problem or constraint that necessitated the decision.
- **Decision:** The chosen technical solution.
- **Reasoning:** Why this option was selected over alternatives.
- **Consequences:** Positive benefits and negative trade-offs.
- **Relevant Files:** Direct links to the implementing source code.
